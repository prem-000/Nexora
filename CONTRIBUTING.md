# Contributing to NEXORA

Please see our comprehensive **[Contribution Guidelines](docs/contribute.md)** in the `docs/` folder for full instructions on:
- Setting up Android Studio, JDK 17, and Android SDK Platform 36
- Coding conventions, Kotlin Coroutines, and MVVM architecture guidelines
- Conventional Commit standards (`feat:`, `fix:`, `docs:`, etc.)
- Multi-device mesh verification and unit testing (`./gradlew test`)
- Submitting Pull Requests

For an architectural overview before contributing, read **[Architecture Specification](docs/arch.md)** and **[Mesh Protocol Specification](docs/mesh.md)**.
